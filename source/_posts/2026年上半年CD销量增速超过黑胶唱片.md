---
title: "2026年上半年CD销量增速超过黑胶唱片"
date: 2026-07-20 10:20:57
categories:
  - HN复读机
---

知名音乐数据机构 Luminate[^1] 发布的 2026 年年中报告称，今年上半年，CD 销量猛增 16%，达到了 1630 万张；而黑胶唱片仅增长了 2.4%。音乐媒体 Consequence[^2] 认为，这证明 CD 复兴潮已经成为实体音乐市场中一股不可忽视的力量。不过，仔细品味这些数据就会发现其中的门道。报告作者自己也提到，BTS[^3] 的新动作（如《ARIRANG》[^4]）贡献了相当大一部分增量。但即便扣除 K-pop 的影响，CD 销量同比依然增长了 6.7%。这个增长是实打实的。虽然算不上滔天巨浪，但也足够平稳，而且背后的原因绝非仅凭一个男子组合就能解释。

在 Hacker News[^5] 社区的讨论中，大家心里都很清楚：核心问题根本不在于音乐载体本身，而在于流媒体服务正在逐渐”崩盘”。一条又一条评论都在吐槽同一个痛点：几年前精心收藏到歌单里的歌曲，往往因为版权协议变动而悄无声息地消失。哪怕 Spotify 平台上其实还有这首歌，只要官方后台改了一下文件 `ID`，你歌单里的原版就会直接变成”不可播放”。花了几年时间心血整理的歌单，渐渐塞满了失效链接。一位资深付费用户看着这种情况频繁发生，最终心灰意冷，觉得留在 Spotify 的生态里”简直毫无价值”。今天辛苦建好的歌单，明天能不能听全凭运气。流媒体根本无法兑现它的承诺。无法真正掌握在手中的东西就不算真正拥有，而服务器端只要改个代码，就能随时将它夺走。

而买 CD 刚好能帮你跳出这个陷阱。好几位网友分享了类似的常规操作：买来唱片，抓轨[^6] 转换成 `FLAC`[^7] 无损音频格式，再把文件永久保存在 `NAS`[^8] 或个人设备里。有人夸这是”两全其美”的方案：既能享有近乎完美的音质，又不用按月交订阅费，更不用担心版权被撤销；同时，架子上的实物 CD 还能当作终极备份。相比之下，玩黑胶得配唱机，还要小心保养；而 CD 几分钟就能抓好轨，导出的文件在任何手机或电脑上都能直接放。这张盘就是你抵御流媒体平台”作妖”的避险保单。这压根不是什么怀旧情结，不过是对一个频频打破信任的服务做出的理性反抗罢了。

正因如此，原文把 CD 的复苏归咎于”怀旧风潮驱动”，实际上错失了核心重点。诚然，怀旧确实占了一部分原因。文章指出，60% 的 Z 世代[^9] 听众表示自己主要听 90 年代或更早期的音乐，而这一比例在 2021 年仅为 18%。不少网友也证实，现在的年轻人到处淘 CD、`iPod` 以及苹果早期的有线耳机，觉得这些东西很”复古”。然而，对流媒体的反感可一点都不复古，这是对当下实际痛点的直接反击。人们买 CD 并不是因为怀念 90 年代，而是因为现在的流媒体越来越不靠谱，软件界面臃肿不堪，商业模式还在源源不断地推送平台自制”垃圾音乐”[^10]，挤压真正音乐人的生存空间。

这里面存在一个相当荒谬的悖论——原文注意到了，但并未深入探讨：CD 销量在蹭蹭上涨，可播放 CD 的设备却快要绝迹了。新车早就不配 CD 播放器了，连最坚守的雷克萨斯也在 2022 年取消了这一配置；笔记本电脑砍掉了光驱；就连长期充当客厅 CD 播放器的游戏主机，也全面转向纯数字版。一位网友说，他女儿买 BTS 的专辑盒收到了一张 CD，结果他发现全家竟然找不到一台设备能放这张盘。另一位网友则吐槽了现在想在车里听一张 CD 需要经过多么荒诞的折腾：先抓轨存进 `NAS`，再通过互联网流媒体传输到手机，最后接上 `Android Auto`[^11] 车机播放。原文还在赞叹 CD 表面那层”绚丽彩虹光泽”的收藏价值，却忽略了一个事实：买那些大盒 K-pop 专辑的人里，很大一部分可能压根没放过里面的光盘。此时的 CD，比起音乐载体，更像是一种小卡或集换卡。

这种”可收藏性”是真实存在的，而且支撑起了相当大一部分市场。塔吉特（Target）和沃尔玛（Walmart）目前占据了实体唱片近 30% 的销量，而 K-pop 组合凭着精美豪华的包装、独家发售版以及一辑多封（鼓励粉丝买多张）的策略，牢牢霸占了这些超市的货架。一位网友提到，他女儿觉得 BTS 专辑里的 CD 看着”挺有意思”，但他很怀疑到底有没有人真拿去听。这与 2010 年代引发的”黑胶复兴”完全是两个维度的市场。买黑胶的人大多是真的打算放出来听；而在 K-pop 圈子里买 CD 的人，很多是为了集齐全套、抽随机小卡[^12]，或者纯粹为了帮偶像冲榜。虽然大家花的都是真金白银，但背后的动机天差地别。

看着 CD 重新吃香，黑胶玩家们也有自己的小算盘：希望强劲的 CD 市场能把”高得离谱”的黑胶价格打下来。但现实恐怕要让他们失望了。道理很简单，黑胶无论在制造、运输还是仓储成本上，都远高于 CD。而且这两种格式定位本就不同：黑胶给你带来的是大尺寸封套和沉浸式的仪式感；CD 带来的则是便捷、易抓轨以及耐用性。不过关于耐用性，大家说法不一。有网友反映自己 90 年代买的 CD 大多因为”光盘腐蚀”[^13] 报废了；但也有人表示自己那个年代收藏的 CD 依然能正常播放，坏的是播放器而不是光盘本身。大家普遍达成的共识是：工业压制的正版 CD 相当耐久，而自己刻录的 `CD-R`[^14] 则容易老化衰退；如果你真的珍惜这些音乐，最好的办法就是抓轨做好数字备份。

讨论中还有一个意想不到的视角——实体音乐与育儿。好几位家长分享道，他们会给小孩子买手提收录机或 CD 播放器，作为无电子屏幕的音乐启蒙工具。他们描述了看着孩子翻阅唱片歌词本、不依赖算法推荐自己做选择、以及学会小心爱护易碎物品的过程。有一位家长甚至给刚会走路的孩子买了费雪（Fisher-Price）磁带机，之所以选磁带而不是 CD，是因为磁带摔不烂。还有人推测，CD 销量中有一大部分贡献正来自于试图让孩子远离电子屏幕的父母。原文并未提及这一点，但这确实是普遍存在的现象。听着 CD 长大的这代父母如今给孩子买 CD，并不是出于怀旧，而是希望亲手交到孩子手里的，是看得见、摸得着的真实存在。

“支持创作者”的论调也贯穿了整个讨论。大家纷纷呼吁直接从音乐人手里购买 CD、黑胶或周边，绕过流媒体平台的剥削。有人将购买实体唱片形容为”一种仪式，一种对创作者表达敬意的实体互动”——音乐是值得珍视的礼物，而不是无脑播放的背景噪音。原文对此表示认同，指出 CD 正充当着”收藏品、粉丝周边以及听众表达爱的渠道”。但社区讨论却给这种浪漫情怀泼了一盆冷水：这真的能帮到音乐人吗？有位网友为了支持独立歌手，特意在 Bandcamp[^15] 平台上购买磁带，结果发现运费和关税吃掉了绝大部分费用，歌手实际能拿到手的微乎其微。后来他干脆改为在”Bandcamp 星期五”[^16]（平台免抽成日）购买数字专辑下载，彻底放弃了实体购买。听众想要支持音乐人的心思是真切的，但实体货物的物流成本，让这份爱意落地变得比想象中难得多。

那么，CD 究竟处于什么位置？它既不会取代黑胶，也不会干掉流媒体，而是精准地卡在一个两者都无法填补的生态位上。流媒体带给你便捷，却不给你所有权；黑胶带给你所有权和仪式感，但价格高昂且极难随身携带。CD 恰好居于两者之间：价格亲民、结实耐用、极易抓轨，且能永久保存。它是那种能让你真正”拥有”且”随时能用”的音乐载体。去掉 K-pop 的水分后，那 16% 的增长数据，诉说了一个微小却真切的变化。人们并没有集体逃离流媒体，但已经有足够多的听众对那种”随时可能收回授权”的服务忍无可忍了。他们选择买 CD，是因为他们想真正”拥有”音乐，而不是向一个连歌单都保不住的公司”租”音乐。

[^1]: Luminate：美国著名的流行音乐与娱乐数据统计机构（前身为 Nielsen Music / 尼尔森音乐），专门追踪全球各类唱片销量及流媒体播放数据。
[^2]: Consequence：业内知名的流行文化与音乐新闻在线媒体（原名 Consequence of Sound）。
[^3]: BTS（防弹少年团）：韩国男子偶像组合，隶属于 HYBE 旗下，全球最具影响力的 K-pop 团体之一，实体专辑销量常年位居榜首。
[^4]: 《ARIRANG》：BTS 于 2026 年发行的专辑/单曲，CD 版本的精美包装和粉丝冲榜行为是推动同期 CD 销量增长的重要因素之一。
[^5]: Hacker News：由硅谷创业孵化器 Y Combinator 运营的知名科技社区，以高质量的技术与产业讨论著称。
[^6]: 抓轨（Ripping）：将 CD 中的音频数据提取并转换为数字音频文件（如 `FLAC`、MP3）的过程。
[^7]: `FLAC`：Free Lossless Audio Codec，一种开源的无损音频压缩编码格式，可在不损失音质的前提下将文件体积压缩至原始大小的一半左右。
[^8]: `NAS`（Network Attached Storage）：网络附加存储设备，可通过局域网或互联网访问，常用于家庭媒体库和个人数据备份。
[^9]: Z 世代（Gen Z）：指 1990 年代末至 2010 年代初（约 1997–2012 年）出生的人群，是互联网时代的第一批数字原住民。
[^10]: “垃圾音乐”：原文作 junk music，指流媒体平台为压低版权支出而批量填充的廉价 AI 生成或低质量背景音乐，常出现在算法推荐歌单中，挤占了真人音乐人的曝光和收入。
[^11]: `Android Auto`：谷歌推出的车载信息娱乐系统，将 Android 手机的核心功能（导航、音乐、通话）投射到车机屏幕上操作。
[^12]: 随机小卡（Photocard）：K-pop 专辑中随机附赠的偶像照片卡片，不同成员、不同款式概率各异，是粉丝重复购买专辑的主要驱动力之一。
[^13]: 光盘腐蚀（Disc Rot）：光盘因铝反射层氧化或保护层化学退化导致数据永久损坏的现象，多见于早期压制的 CD 和劣质刻录盘。
[^14]: `CD-R`（CD-Recordable）：一次性可刻录光盘，用户可写入数据但无法擦除，染料层会随时间自然老化，寿命远低于工业压制的正版 CD。
[^15]: Bandcamp：面向独立音乐人的在线音乐销售与流媒体平台，以对创作者友好的分成模式著称，支持购买实体唱片和数字下载。
[^16]: Bandcamp 星期五（Bandcamp Fridays）：Bandcamp 平台推出的特别免抽成日（通常为每月第一个星期五），当天粉丝购买音乐的所有收入将 100% 归音乐人所有。
