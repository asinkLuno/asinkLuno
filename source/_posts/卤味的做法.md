## 配方

以下用量适用于 **2 斤原料**。

| 材料 | 用量 |
| --- | ---: |
| 生抽 | 120 克 |
| 盐 | 14 克 |
| 黄酒 | 75 克 |
| 冰糖 | 25 克 |
| 味精 | 6 克 |
| 老姜 | 35 克 |
| 大蒜 | 35 克 |
| 腐乳 | 2 块 |
| 卤料包 | 1 包 |
| 花椒 | 适量 |

味精也可以换成 **3 克鸡精**。
